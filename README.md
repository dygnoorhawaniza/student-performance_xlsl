# 🎓 Student Performance Analysis

An exploratory data analysis and **Power BI dashboard** project focused on understanding student performance using academic data.

The project includes a cleaned dataset prepared in Excel and an interactive Power BI dashboard for exploring performance patterns.

---

## 📊 Dashboard

The Power BI dashboard provides a visual overview of student performance and allows users to explore the data through interactive charts and filters.
